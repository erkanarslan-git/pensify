- Guest message templates are organization-scoped, language-specific overrides with built-in fallbacks; booking substitution has no access secrets and runs once. Why: customization must preserve code privacy and guest-language selection.- Invoices are created only via create_invoice RPC (server-side totals, gross prices, locked org numbering with editable format/next number, issuer snapshot); rows are immutable apart from sent_at. Why: legal invoice numbers must be unique and history unchanged.
- Calendar overview periods use the board's shared selected date; every date control updates it. Why: monthly and yearly occupancy must follow the visible date rather than an independent current-month anchor.
- Voice agent calls arrive only via signed ElevenLabs post-call webhook (ELEVENLABS_WEBHOOK_SECRET), mapped to an org by agent_id; voice tables are owner/admin-only. Why: call transcripts are private and unsigned callers must not write.
- Dashboard per-property cards combine live room status with today's reservations (src/lib/dashboard-today.ts); every number links to a pre-filtered list via search params. Why: one consistent count source and clickable stats.
